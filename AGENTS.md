# AGENTS.md

## Project Overview
- Curated list of AI agent desktop applications.
- Primary content lives in `README.md` under "Agent Desktop Clients".

## Edit Guidelines
- Add new entries only to the list in `README.md`.
- Format each item as: `- [Name](URL) - Short description`.
- Keep the existing ordering and style; maintain alphabetical order.
- For GitHub open-source projects, use the GitHub repo link and its description.
- For non-GitHub items, use the official website and its description.
- Use plain ASCII text unless the source name requires otherwise.

## Validation
- No automated tests or linters are configured.
- Optionally spot-check that new links are valid.
