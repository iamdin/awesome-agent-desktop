# AGENTS.md

## Project Overview
- Curated list of AI agent products.
- Primary content lives in `README.md`, split into sections by product form factor.

## Scope
- In scope: finished, user-facing products someone can install or sign up for.
- Out of scope: frameworks, SDKs, agent libraries, MCP servers, and other building blocks.
- When a product spans several form factors, file it under the one it leads with.

## Sections
- Desktop Apps
- Agentic IDEs and Editors
- Terminal and CLI Agents
- Terminal Multiplexers and Session Managers
- Web, Mobile, and Remote Clients
- Session Monitors and Companion Tools

Add a new section only when at least three entries would live in it, and add it to the Contents list at the same time.

## Edit Guidelines
- Format each item as: `- [Name](URL) - Short description.`
- Descriptions are one line, start with a capital letter, and end with a period.
- Maintain case-insensitive alphabetical order within each section.
- For GitHub open-source projects, use the GitHub repo link and its description.
- For non-GitHub items, use the official website and its description.
- Use plain ASCII text unless the source name requires otherwise.
- Disambiguate same-named projects with a parenthetical owner, e.g. `openwork (different-ai)`.

## Validation
- No automated tests or linters are configured.
- Check that new links resolve, and that GitHub links are not redirects from a renamed or transferred repo.
